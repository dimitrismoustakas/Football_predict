# Experiment Reports

Use this folder for finished experiment writeups produced by the proposal-runner workflow.

## Naming

Use:

- `YYYY-MM-DD_<idea-id>_<slug>.md`

Example:

- `2026-03-07_P007_missing-value-flags.md`

## Expectations

Each report should:

- identify the exact proposal from `improvement_proposals.md`
- summarize the implementation
- list the files changed
- list the commands run
- capture rolling-CV, held-out, slice, and stability evidence
- draft the scorecard evidence
- leave the final promotion decision to the separate promotion workflow unless that workflow is currently running

## Source documents

Reports should align with:

- `docs/evaluation_policy.md`
- `docs/model_acceptance_scorecard_template.md`
- `.github/skills/proposal-runner/report-template.md`
